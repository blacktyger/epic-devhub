# Start your Epic developer journey

Eight stages. By the end you will have built the binaries, mined your own chain, moved coins across
it, and driven a wallet from code.

Stages 03 to 05 run on a private chain you create yourself, with coins you mint. It behaves exactly
like mainnet and touches nothing on it.

## What this version does not cover

**Tor.** Release archives do not include the `tor` binary required by the wallet's onion listener. The
wallet's `use_tor_listener` setting defaults to `true`, so a plain `epic-wallet listen` can fail in a
background thread. Set `use_tor_listener = false` in `epic-wallet.toml`, or pass `-n` on every `listen`.
Tor operation is not documented or runtime-verified here; its configuration keys remain listed in the
[wallet](/reference/wallet-config) and [node](/reference/node-config) references.
