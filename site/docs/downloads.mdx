export const nodeAsset = (key) => releases.node.assets.find((a) => a.key === key);
export const walletAsset = (key) => releases.wallet.assets.find((a) => a.key === key);
export const sumFile = (file) => `${file.replace(/\.(tar\.gz|zip|exe)$/, '')}-sha256sum.txt`;

# Downloads

Prebuilt binaries are published on GitHub releases. The Linux binaries link against `GLIBC_2.39`, so
they need glibc 2.39 or newer, which means Ubuntu 24.04 or later.

To build from source instead, see [build the binaries](/guides/build).

## Node <Ver k="node" /> {/* #node-ver-knode- */}

Release <a href={releases.node.url}>tag v<Ver k="node" /></a>, or the{' '}
<a href={releases.node.latest}>latest release</a> and <a href={releases.node.all}>all releases</a>.

| Platform | Asset | Unpacks to |
| --- | --- | --- |
| {nodeAsset('linux').platform} | <code>{nodeAsset('linux').file}</code> | <code>{releases.node.unpacksTo.linux}/</code> |
| {nodeAsset('mac').platform} | <code>{nodeAsset('mac').file}</code> | <code>{releases.node.unpacksTo.mac}/</code> |
| {nodeAsset('windows').platform} | <code>{nodeAsset('windows').file}</code> | `epic.exe`, no wrapping directory |

macOS Intel and Linux ARM need a source build.

## Wallet <Ver k="wallet" /> {/* #wallet-ver-kwallet- */}

Release <a href={releases.wallet.url}>tag v<Ver k="wallet" /></a>, or the{' '}
<a href={releases.wallet.latest}>latest release</a> and <a href={releases.wallet.all}>all releases</a>.

| Platform | Asset | Unpacks to |
| --- | --- | --- |
| {walletAsset('linux').platform} | <code>{walletAsset('linux').file}</code> | `epic-wallet`, no wrapping directory |
| {walletAsset('windows').platform} | <code>{walletAsset('windows').file}</code> | the executable itself, not an archive |

The archive is named for the 4.0 line rather than the full <Ver k="wallet" /> tag, and holds a Linux
x86-64 ELF binary.

## Download and verify {/* #download-and-verify */}

Each asset publishes a checksum file beside it, named for the asset with its extension replaced by
`-sha256sum.txt`: <code>{sumFile(nodeAsset('linux').file)}</code> for the Linux node tarball,
<code>{sumFile(walletAsset('linux').file)}</code> for the wallet archive.

<Tabs groupId="os">
<TabItem value="linux" label="Linux">

```bash
curl -LO https://github.com/EpicCash/epic/releases/download/v4.0.3/epic-4.0.3-linux-amd64.tar.gz
curl -LO https://github.com/EpicCash/epic/releases/download/v4.0.3/epic-4.0.3-linux-amd64-sha256sum.txt

sha256sum -c epic-4.0.3-linux-amd64-sha256sum.txt
# expect: epic-4.0.3-linux-amd64.tar.gz: OK

tar xzf epic-4.0.3-linux-amd64.tar.gz
./epic --usernet
```

</TabItem>
<TabItem value="mac" label="macOS">

```bash
curl -LO https://github.com/EpicCash/epic/releases/download/v4.0.3/MacOS-aarch64-4.0.3.zip
curl -LO https://github.com/EpicCash/epic/releases/download/v4.0.3/MacOS-aarch64-4.0.3-sha256sum.txt

shasum -a 256 -c MacOS-aarch64-4.0.3-sha256sum.txt
unzip MacOS-aarch64-4.0.3.zip
```

Gatekeeper refuses an unsigned binary on first run. Allow it in System Settings, Privacy and
Security.

</TabItem>
<TabItem value="win" label="Windows">

```powershell
$tag = 'v4.0.3'
$base = "https://github.com/EpicCash/epic/releases/download/$tag"
Invoke-WebRequest "$base/Windows-$tag.zip" -OutFile "Windows-$tag.zip"
Invoke-WebRequest "$base/Windows-$tag-sha256sum.txt" -OutFile "sha256sum.txt"

# PowerShell has no `sha256sum -c`, so compare the two values.
(Get-FileHash "Windows-$tag.zip" -Algorithm SHA256).Hash.ToLower()
Get-Content sha256sum.txt

Expand-Archive "Windows-$tag.zip" -DestinationPath .
```

</TabItem>
</Tabs>

:::note
Release binaries are built without `--features with-tor`, so they ship no Tor support. Set
`use_tor_listener = false` in [epic-wallet.toml](/reference/wallet-config), or build from source with
the feature.
:::
