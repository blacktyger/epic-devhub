# Stratum

The node includes a Stratum server for miners. It listens on `127.0.0.1:3416` by default, 13416 on
floonet and 23416 on usernet, and it is off unless `enable_stratum_server` is set.

It is off on **every** network, usernet included.
<Src repo="node" path="servers/src/common/types.rs" line={301} /> has a `UserTesting` branch that
sets it `true`, and that branch never executes: the `Default` impl reads the process-global chain
type, which is still `Mainnet` at the point a config file is generated. A usernet
`epic-server.toml` comes out with `enable_stratum_server = false`.

## Transport

**Raw TCP with newline-delimited JSON.** Each JSON-RPC message is one line terminated by a newline. There
are no HTTP headers, paths or status codes.

## Authentication

There is none. Any client that can open the port can request work and submit shares.

A `login` method exists and is accepted, alongside `keepalive` and `status`. It records a worker name and
sets an `authenticated` flag that nothing ever reads, and the password is not checked
(<Src repo="node" path="servers/src/mining/stratumserver.rs" line={930} />).

## Requesting work

A node returns `-32000 Node is syncing - Please wait` when `peer_min_preferred_outbound_count` outbound
peers have not been reached. On usernet (no peers by design) set this to `0` or the node stays in syncing
state permanently. See [run a local network](/guides/local-network#why-usernet).

`getjobtemplate` requires an `algorithm` parameter naming which of the three proof-of-work algorithms you
intend to mine. Epic runs all three concurrently, so a job is algorithm-specific. See
[proof of work](/mining/proof-of-work).

The algorithm you get back is the one the policy requires at that height, not necessarily the one you
asked for. A miner that only supports one algorithm therefore sits idle on the heights assigned to the
others, and `epic-miner` logs this as `my algo: randomx, algo from job progpow` followed by `0 hps`.
Covering a mixed policy needs one miner per algorithm; restricting the policy with `only_randomx` is
the alternative on a private chain.

The job template carries `height`, `job_id`, `pre_pow`, `algorithm`, `epochs`, and both `difficulty` and
`block_difficulty` as arrays of `[algorithm_name, value]` pairs rather than single values
(<Src repo="node" path="servers/src/mining/stratumserver.rs" line={176} />).

## Submitting shares

`submit` takes `height`, `job_id`, `nonce` as a number, and `pow`. `pow` is an externally tagged enum, so
it is a single-key object whose value is a tuple: `{"Cuckoo": [edge_bits, [nonces]]}`,
`{"RandomX": [32 bytes]}` or `{"ProgPow": [32 bytes]}`. Edge bits are the first element of the Cuckoo
tuple rather than a sibling field
(<Src repo="node" path="servers/src/mining/stratumserver.rs" line={161} />).

## Methods

`login`, `submit`, `keepalive`, `getjobtemplate`, `status`. Anything else returns `-32601`.

## Error codes

Errors follow JSON-RPC conventions, except that the internal error is emitted as `32603` rather than the
specified `-32603`. Match on the absolute value if you need to detect it reliably.

## Mining over HTTP instead

The node's foreign JSON-RPC surface offers `get_block_template`, `finalize_block_template` and
`submit_block`. It is ordinary JSON-RPC over HTTP and is often simpler to work with than the socket
protocol. See [the node API](/api/node#mining-over-http).

## Message reference

Message shapes below are the current field sets. Exact serialisation is defined by the structs in
<Src repo="node" path="servers/src/mining/stratumserver.rs" />.

### Requesting a job

```json title="client -> server, one line"
{"id":"1","jsonrpc":"2.0","method":"getjobtemplate","params":{"algorithm":"randomx"}}
```

### Submitting a share

```json title="client -> server, one line"
{"id":"2","jsonrpc":"2.0","method":"submit","params":{
  "height":1000001,
  "job_id":7,
  "nonce":13476209874311234567,
  "pow":{"RandomX":[10,27,44,3,255,18,9,72,64,31,88,120,4,17,203,55,
                    91,6,142,77,38,199,15,60,231,2,113,49,86,170,25,8]}
}}
```

A Cuckatoo share puts edge bits first and the nonce list second. The list holds 42 entries:

```json title="client -> server, one line"
{"id":"3","jsonrpc":"2.0","method":"submit","params":{
  "height":1000001,"job_id":7,"nonce":42,
  "pow":{"Cuckoo":[31,[1042,20984,31006]]}
}}
```

### Watch a live session

You can observe a live session with `nc`:

```bash
# Enable the server first: stratum_mining_config.enable_stratum_server = true
printf '{"id":"1","jsonrpc":"2.0","method":"getjobtemplate","params":{"algorithm":"randomx"}}\n' \
  | nc 127.0.0.1 3416
```

```python title="stratum_probe.py"
"""Connect to the Stratum server, request one job per algorithm, print the replies."""

import json
import socket

HOST, PORT = "127.0.0.1", 3416
ALGORITHMS = ("randomx", "progpow", "cuckatoo")


def probe() -> None:
    with socket.create_connection((HOST, PORT), timeout=15) as sock:
        stream = sock.makefile("rw", encoding="utf-8", newline="\n")

        for index, algorithm in enumerate(ALGORITHMS, start=1):
            request = {
                "id": str(index),
                "jsonrpc": "2.0",
                "method": "getjobtemplate",
                "params": {"algorithm": algorithm},
            }
            # Newline-delimited JSON over raw TCP. There is no HTTP framing.
            stream.write(json.dumps(request) + "\n")
            stream.flush()

            line = stream.readline()
            if not line:
                print(f"{algorithm}: connection closed")
                return
            print(f"{algorithm}: {json.dumps(json.loads(line), indent=2)}")


if __name__ == "__main__":
    probe()
```

<TabItem value="js" label="JavaScript">

```js title="stratumProbe.mjs"
import net from 'node:net';

const ALGORITHMS = ['randomx', 'progpow', 'cuckatoo'];

const socket = net.createConnection({host: '127.0.0.1', port: 3416}, () => {
  ALGORITHMS.forEach((algorithm, index) => {
    // Newline-delimited JSON over raw TCP. There is no HTTP framing.
    socket.write(
      JSON.stringify({
        id: String(index + 1),
        jsonrpc: '2.0',
        method: 'getjobtemplate',
        params: {algorithm},
      }) + '\n',
    );
  });
});

let buffer = '';
socket.on('data', (chunk) => {
  buffer += chunk.toString();
  let newline;
  while ((newline = buffer.indexOf('\n')) !== -1) {
    const line = buffer.slice(0, newline).trim();
    buffer = buffer.slice(newline + 1);
    if (line) console.log(JSON.stringify(JSON.parse(line), null, 2));
  }
});

socket.on('error', (err) => console.error('stratum error:', err.message));
```
