# SDK dashboard

`epic-sdk serve` предоставляет браузерный интерфейс над локальным окружением Epic. Запускает и останавливает
узел, слушателей кошелька, майнер и релей, считывает балансы, редактирует файлы конфигурации и
выполняет команды Epic.

```bash
uv sync --extra cli --extra service
epic-sdk serve --root ~/epic-lab
```

Сервер работает на `127.0.0.1`, порт <Ver k="ports.sdkDashboard" />.

| Опция | Default | Назначение |
| --- | --- | --- |
| `--root` | `~/emulator` | Каталог окружения. `EPIC_DEV_ROOT` устанавливает то же самое. |
| `--port` | <Ver k="ports.sdkDashboard" /> | `EPIC_DASHBOARD_PORT` устанавливает то же самое. |
| `--host` | `127.0.0.1` | Адрес привязки. |
| `--open` |  | Открывает браузер. |
| `--allow-send` |  | Монтирует вкладку переводов. Только usernet. |

Запускается с окружением или без него. При отсутствии окружения вкладка Network создаёт его.

Без `--allow-send` маршруты перевода не монтируются, поэтому ни один запрос интерфейса не перемещает средства.
При его наличии каждый запрос перевода проверяет, что цепочка является usernet. Пароль кошелька
распечатывается в серверном процессе для одного вызова Owner API и никогда не включается в ответ.

## Процессы {/* #processes */}

Вкладка по умолчанию: по одной карточке на каждый процесс — узел, слушатель кошелька, Owner API
кошелька, майнер и релей. Каждая карточка содержит кнопки Start, Stop, Restart, текущее состояние и
лог.

Start all и Stop all находятся в заголовке. Запуск всех выполняется в порядке зависимостей,
остановка всех — в обратном порядке.

Второй панели перечислены все процессы Epic, запущенные на машине, включая те, которые данное
окружение не запускало; любой из них можно завершить по имени. Панель лога отслеживает выбранный
процесс и следует за ним.

Кошельки, созданные `epic-sdk`, запускаются и отображаются здесь. Кошелёк, принятый из существующего
дерева, отображается с указанием причины, по которой его элементы управления неактивны, и никогда не
открывается.

## Кошельки {/* #wallets */}

По одной строке на каждый экземпляр кошелька: имя, роль, управляется ли окружением, состояние Owner
API и слушателя, а также доступный к трате и общий баланс. Update обновляет баланс одного кошелька с
узла.

Считывание баланса использует Owner API, если он запущен, и бинарный файл `epic-wallet`, если нет.

## Сеть {/* #network */}

Окружения, хранящиеся на данной машине, и форма для создания нового. Два режима: local — с
собственным узлом, и remote — только кошельки, подключённые к узлу на другой машине.

Также содержит инвентарь программного обеспечения с указанием версий относительно upstream и кнопкой
установки рядом; пробу доступности узла, на который указывает кошелёк; хранимый секрет для
удалённого узла, который отображается как присутствующий без раскрытия содержимого; и `epic-wallet init` для
кошелька в удалённом окружении в виде двухшагового процесса.

Длительные операции выполняются как задание. Панель вывода транслирует его в реальном времени, Stop
завершает его.

## Конфигурация {/* #config */}

TOML-файлы окружения, по одной вкладке на каждый: узел, майнер и каждый кошелёк. Каждый отображает
разобранные настройки с фильтром и необработанный текст.

Редактирование записывает один ключ и считывает его обратно через парсер, поэтому отображаемое после
этого значение является значением, которое файл теперь содержит. Ключи, определяющие окружение, в
том числе `chain_type` и `db_root`, отклоняются.

## Перевод {/* #transfer */}

Отображается, когда `epic-sdk serve --allow-send` запустил сервер на цепочке usernet.

Отправитель и получатель выбираются из кошельков окружения. Форма принимает сумму, транспорт epicbox
или file и сообщение. Таблица готовности показывает, какие транспорты могут выполнить перевод прямо
сейчас; шаг проверки отображает, что будет отправлено; переводы текущей сессии перечислены ниже.

<Risk level="spend" /> Перевод здесь — это реальная транзакция в цепочке, которую запускает окружение, включая её
комиссию.

## Обозреватель {/* #explorer */}

Обозреватель блоков над локальной цепочкой: высота блока, время блока, объём эмиссии, количество
UTXO, количество транзакций, последние блоки и ядра, а также поиск по высоте блока, хешу блока,
превышению ядра или обязательству (commitment).

Считывает индекс PostgreSQL, поэтому требует дополнение `explorer`:

```bash
uv sync --extra cli --extra service --extra explorer
```

Остальная часть дашборда работает без него.

## Консоль {/* #console */}

<kbd>Ctrl</kbd> + <kbd>&#96;</kbd> открывает панель, в которой выполняются команды Epic по имени: `epic-sdk`,
`epic`, узел, `epic-wallet` и `epic-miner`. Разрешает введённую команду и показывает, что будет выполнено, до запуска;
предлагает варианты дополнения и отвечает на `--help` из самого бинарного файла.

Не запускает оболочку и не принимает пути. Команда, которая тратит средства, требует `--allow-send` на
сервере; флаг пароля отклоняется.
