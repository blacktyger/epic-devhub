export const nodeAsset = (key) => releases.node.assets.find((a) => a.key === key);
export const walletAsset = (key) => releases.wallet.assets.find((a) => a.key === key);
export const sumFile = (file) => `${file.replace(/\.(tar\.gz|zip|exe)$/, '')}-sha256sum.txt`;

# Загрузки

Готовые бинарники публикуются в релизах GitHub. Linux-бинарники <Ver k="node" /> как узла, так и кошелька
скомпонованы с `GLIBC_2.34`, поэтому им требуется glibc 2.34 или новее, то есть Ubuntu 22.04, Debian 12 или
более поздние версии.

Чтобы вместо этого собрать из исходников, см. [собрать бинарники](/guides/build).

## Узел <Ver k="node" /> {/* #node-ver-knode- */}

Релиз <a href={releases.node.url}>tag v<Ver k="node" /></a>, или{' '} <a href={releases.node.latest}>последний релиз</a> и <a href={releases.node.all}>все релизы</a>.

{releases.node.binariesStale && (

      <code>{releases.node.binariesVersion}</code> is a restored API basic-auth middleware plus
      version and documentation-URL bumps.
    </p>

)}

| Платформа | Файл | Распаковывается в |
| --- | --- | --- |
| {nodeAsset('linux').platform} | <code>{nodeAsset('linux').file}</code> | <code>{releases.node.unpacksTo.linux}/epic</code> |
| {nodeAsset('windows').platform} | <code>{nodeAsset('windows').file}</code> | <code>{releases.node.unpacksTo.windows}/epic.exe</code> |

Релиз <Ver k="node" /> не публикует бинарник для macOS. Последний доступный находится{' '} <code>{releases.node.mac.file}</code> на
<a href={releases.node.mac.url}>tag v{releases.node.mac.version}</a>, в более старом релизе; чтобы запустить <Ver k="node" /> на Mac, [соберите из
исходников](/guides/build). macOS Intel и Linux ARM также требуют сборки из исходников.

## Кошелёк <Ver k="wallet" /> {/* #wallet-ver-kwallet- */}

Релиз <a href={releases.wallet.url}>tag v<Ver k="wallet" /></a>, или{' '} <a href={releases.wallet.latest}>последний релиз</a> и <a href={releases.wallet.all}>все релизы</a>.

| Платформа | Файл | Распаковывается в |
| --- | --- | --- |
| {walletAsset('linux').platform} | <code>{walletAsset('linux').file}</code> | <code>{releases.wallet.unpacksTo.linux}/epic-wallet</code> |
| {walletAsset('windows').platform} | <code>{walletAsset('windows').file}</code> | <code>{releases.wallet.unpacksTo.windows}/epic-wallet.exe</code> |

Архив кошелька для Windows именуется с подчёркиванием: <code>{walletAsset('windows').file}</code>, тогда как у узла
используется дефис. Бинарник кошелька для macOS не публикуется.

## Скачать и проверить {/* #download-and-verify */}

Рядом с каждым файлом публикуется файл контрольной суммы, имя которого совпадает с именем файла, но
расширение заменено на `-sha256sum.txt`: <code>{sumFile(nodeAsset('linux').file)}</code> для Linux-тарбола узла, <code>{sumFile(walletAsset('linux').file)}</code> для
Linux-тарбола кошелька. Опубликованные значения SHA-256 для <Ver k="node" />:

| Файл | SHA-256 |
| --- | --- |
| <code>{nodeAsset('linux').file}</code> | <code>{nodeAsset('linux').sha256}</code> |
| <code>{nodeAsset('windows').file}</code> | <code>{nodeAsset('windows').sha256}</code> |
| <code>{walletAsset('linux').file}</code> | <code>{walletAsset('linux').sha256}</code> |
| <code>{walletAsset('windows').file}</code> | <code>{walletAsset('windows').sha256}</code> |

<Tabs groupId="os">
<TabItem value="linux" label="Linux">

<CodeBlock language="bash">{`curl -LO ${releases.node.download}/${nodeAsset('linux').file}
curl -LO ${releases.node.download}/${sumFile(nodeAsset('linux').file)}

sha256sum -c ${sumFile(nodeAsset('linux').file)}
# expect: ./${nodeAsset('linux').file}: OK

tar xzf ${nodeAsset('linux').file}
./${releases.node.unpacksTo.linux}/epic --version

curl -LO ${releases.wallet.download}/${walletAsset('linux').file}
curl -LO ${releases.wallet.download}/${sumFile(walletAsset('linux').file)}

sha256sum -c ${sumFile(walletAsset('linux').file)}
# expect: ./${walletAsset('linux').file}: OK

tar xzf ${walletAsset('linux').file}
./${releases.wallet.unpacksTo.linux}/epic-wallet --version`}</CodeBlock>

</TabItem>
<TabItem value="mac" label="macOS">

Бинарника <Ver k="node" /> для macOS для скачивания нет. [Соберите из исходников](/guides/build) на теге <code>v<Ver k="node" /></code>.
Последний готовый бинарник узла для macOS относится к более старому релизу,{' '} <a href={releases.node.mac.url}>v{releases.node.mac.version}</a>,
который вышел до{' '} изменений аутентификации <Ver k="node" /> API: он ведёт себя не так, как описано в
[аутентификация и TLS](/api/authentication), и не должен использоваться совместно с кошельком <Ver k="wallet" />.

<CodeBlock language="bash">{`curl -LO ${releases.node.mac.download}/${releases.node.mac.file}
curl -LO ${releases.node.mac.download}/${sumFile(releases.node.mac.file)}

shasum -a 256 -c ${sumFile(releases.node.mac.file)}
unzip ${releases.node.mac.file}`}</CodeBlock>

Gatekeeper отклоняет неподписанный бинарник при первом запуске. Разрешите его в System Settings,
Privacy and Security.

</TabItem>
<TabItem value="win" label="Windows">

<CodeBlock language="powershell">{`$tag = 'v${releases.node.binariesVersion}'
$base = "https://github.com/EpicCash/epic/releases/download/$tag"
Invoke-WebRequest "$base/Windows-$tag.zip" -OutFile "Windows-$tag.zip"
Invoke-WebRequest "$base/Windows-$tag-sha256sum.txt" -OutFile "sha256sum.txt"

# PowerShell has no \`sha256sum -c\`, so compare the two values.
(Get-FileHash "Windows-$tag.zip" -Algorithm SHA256).Hash.ToLower()
Get-Content sha256sum.txt

Expand-Archive "Windows-$tag.zip" -DestinationPath .
.\\Windows-$tag\\epic.exe --version

# The wallet archive is named with an underscore, not a hyphen.
$wbase = "https://github.com/EpicCash/epic-wallet/releases/download/v${versions.wallet}"
Invoke-WebRequest "$wbase/${walletAsset('windows').file}" -OutFile "${walletAsset('windows').file}"
Invoke-WebRequest "$wbase/${sumFile(walletAsset('windows').file)}" -OutFile "wallet-sha256sum.txt"
(Get-FileHash "${walletAsset('windows').file}" -Algorithm SHA256).Hash.ToLower()
Get-Content wallet-sha256sum.txt
Expand-Archive "${walletAsset('windows').file}" -DestinationPath .`}</CodeBlock>

</TabItem>
</Tabs>

:::note
Релизные бинарники собраны без `--features with-tor`, поэтому поддержка Tor в них отсутствует. Задайте `use_tor_listener = false` в
[epic-wallet.toml](/reference/wallet-config) или соберите из исходников с этой функцией.
:::
