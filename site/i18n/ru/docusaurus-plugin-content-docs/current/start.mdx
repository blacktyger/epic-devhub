# Начало пути разработчика Epic

Восемь этапов. По завершении вы соберёте бинарники, намайните собственную цепочку, переведёте монеты
по ней и будете управлять кошельком из кода.

Этапы 03–05 выполняются на приватной цепочке, которую вы создаёте самостоятельно, с монетами
собственной чеканки. Она ведёт себя в точности как mainnet и никак с ним не взаимодействует.

## Что не охвачено в этой версии {/* #what-this-version-does-not-cover */}

**Tor.** Архивы релизов не включают бинарник `tor`, который требуется слушателю onion кошелька, а `use_tor_listener`
по умолчанию использует `true`, поэтому обычный `epic-wallet listen` может завершиться ошибкой в фоновом потоке. В
разделе [Отключить слушатель Tor](/guides/mainnet-setup#turn-off-the-tor-listener) описано необходимое изменение. Ключи конфигурации Tor
перечислены в справочниках [кошелька](/reference/wallet-config) и [узла](/reference/node-config).
