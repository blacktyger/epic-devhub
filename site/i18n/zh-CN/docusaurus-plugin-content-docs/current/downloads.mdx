export const sumFile = (file) => `${file.replace(/\.(tar\.gz|zip|exe)$/, '')}-sha256sum.txt`;

# 下载

预构建的二进制文件发布在GitHub releases上。<Ver k="node" /> Linux二进制文件（节点和钱包均包含）链接到<code>GLIBC_<Ver k="linuxGlibc" /></code>，因此需要glibc <Ver k="linuxGlibc" />或更新版本，即Ubuntu 22.04、Debian 12或更高版本。

如需从源码构建，请参阅[构建二进制文件](/guides/build)。

## 节点 <Ver k="node" /> {/* #node-ver-knode- */}

发布版本<a href={releases.node.url}>tag v<Ver k="node" /></a>，或查看{' '} <a href={releases.node.latest}>最新发布版本</a>和<a href={releases.node.all}>所有发布版本</a>。

发布版本<a href={releases.wallet.url}>tag v<Ver k="wallet" /></a>，或查看{' '} <a href={releases.wallet.latest}>最新发布版本</a>和<a href={releases.wallet.all}>所有发布版本</a>。

| 平台 | 资源文件 | 解压至 |
| --- | --- | --- |
| {walletAsset('linux').platform} | <code>{walletAsset('linux').file}</code> | <code>{releases.wallet.unpacksTo.linux}/epic-wallet</code> |
| {walletAsset('windows').platform} | <code>{walletAsset('windows').file}</code> | <code>{releases.wallet.unpacksTo.windows}/epic-wallet.exe</code> |

钱包的Windows压缩包名称使用下划线，即<code>{walletAsset('windows').file}</code>，而节点使用连字符。未发布macOS钱包二进制文件。

## 下载并验证 {/* #download-and-verify */}

每个资产旁边都附有一个校验和文件，文件名与资产相同但扩展名替换为`-sha256sum.txt`：Linux节点tarball对应<code>{sumFile(nodeAsset('linux').file)}</code>，Linux钱包tarball对应<code>{sumFile(walletAsset('linux').file)}</code>。<Ver k="node" />已发布的SHA-256值如下：

| 资源文件 | SHA-256 |
| --- | --- |
| <code>{nodeAsset('linux').file}</code> | <code>{nodeAsset('linux').sha256}</code> |
| <code>{nodeAsset('windows').file}</code> | <code>{nodeAsset('windows').sha256}</code> |
| <code>{walletAsset('linux').file}</code> | <code>{walletAsset('linux').sha256}</code> |
| <code>{walletAsset('windows').file}</code> | <code>{walletAsset('windows').sha256}</code> |

<Tabs groupId="os">
<TabItem value="linux" label="Linux">

<CodeBlock language="bash">{`curl -LO ${releases.node.download}/${nodeAsset('linux').file}
curl -LO ${releases.node.download}/${sumFile(nodeAsset('linux').file)}

sha256sum -c ${sumFile(nodeAsset('linux').file)}
# expect: ./${nodeAsset('linux').file}: OK

tar xzf ${nodeAsset('linux').file}
./${releases.node.unpacksTo.linux}/epic --version

curl -LO ${releases.wallet.download}/${walletAsset('linux').file}
curl -LO ${releases.wallet.download}/${sumFile(walletAsset('linux').file)}

sha256sum -c ${sumFile(walletAsset('linux').file)}
# expect: ./${walletAsset('linux').file}: OK

tar xzf ${walletAsset('linux').file}
./${releases.wallet.unpacksTo.linux}/epic-wallet --version`}</CodeBlock>

</TabItem>
<TabItem value="mac" label="macOS">

<Ver k="node" />没有可下载的macOS二进制文件。请在tag <code>v<Ver k="node" /></code>处[从源码构建](/guides/build)。最后一个预构建的macOS节点来自较旧的发布版本{' '} <a href={releases.node.mac.url}>v{releases.node.mac.version}</a>，该版本早于{' '} <Ver k="history.authChange" /> API身份验证变更：其行为与[身份验证与TLS](/api/authentication)所描述的不符，不应与钱包<Ver k="wallet" />配合使用。

<CodeBlock language="bash">{`curl -LO ${releases.node.mac.download}/${releases.node.mac.file}
curl -LO ${releases.node.mac.download}/${sumFile(releases.node.mac.file)}

shasum -a 256 -c ${sumFile(releases.node.mac.file)}
unzip ${releases.node.mac.file}`}</CodeBlock>

Gatekeeper在首次运行时拒绝未签名的二进制文件。在系统设置的"隐私与安全性"中允许运行。

</TabItem>
<TabItem value="win" label="Windows">

<CodeBlock language="powershell">{`$file = '${nodeAsset('windows').file}'
Invoke-WebRequest "${nodeAsset('windows').url}" -OutFile $file
Invoke-WebRequest "${nodeAsset('windows').sumUrl}" -OutFile "sha256sum.txt"

# PowerShell has no \`sha256sum -c\`, so compare the two values.
(Get-FileHash $file -Algorithm SHA256).Hash.ToLower()
Get-Content sha256sum.txt

Expand-Archive $file -DestinationPath .
.\\${nodeAsset('windows').binary.replaceAll('/', '\\')} --version

# The wallet archive is named with an underscore, not a hyphen.
Invoke-WebRequest "${walletAsset('windows').url}" -OutFile "${walletAsset('windows').file}"
Invoke-WebRequest "${walletAsset('windows').sumUrl}" -OutFile "wallet-sha256sum.txt"
(Get-FileHash "${walletAsset('windows').file}" -Algorithm SHA256).Hash.ToLower()
Get-Content wallet-sha256sum.txt
Expand-Archive "${walletAsset('windows').file}" -DestinationPath .`}</CodeBlock>

</TabItem>
</Tabs>

:::note
发布版本的二进制文件构建时未启用`--features with-tor`，因此不包含Tor支持。请在[epic-wallet.toml](/reference/wallet-config)中设置`use_tor_listener = false`，或从源码构建并启用该功能。
:::
